Install a [repository-built tarball](../install-cli/)
before running these commands. The command is `planview`, including while the
product is named plansplease.

## Local snapshots

```sh
planview publish --open ./report.html
planview publish --json ./report.html
planview publish --open ./artifact/
```

A file must be `.html` or `.htm`. A folder must have root `index.html` and may
contain up to 512 regular files. The encoded snapshot, including a folder's
manifest, must fit within 10 MiB. Symlink sources are rejected.

Each publication creates an immutable snapshot. The daemon prefers port 4777
and selects another available port when necessary. Use the exact printed URL.
Folder pages resolve their assets beneath that URL; the browser follows a root
redirect to serve `index.html`.

### Retrieve a standalone snapshot

```sh
planview get <id-or-exact-local-url> > recovered.html
```

`get` writes exact HTML bytes to standard output. It accepts local references
for the selected profile's current port, not cloud links. Current CLI retrieval
does not follow the folder-root redirect, so use the browser to view a local
artifact folder and its assets.

## Daemon and profiles

```sh
planview status --json
planview start
planview stop
planview restart
planview clean
planview --profile work publish ./report.html
```

`status` inspects without starting the daemon. `clean` removes snapshots older
than 30 days since last access and reconciles incomplete storage operations.
The daemon runs that cleanup at startup and every 24 hours. Profiles isolate
local documents, daemon state, and saved cloud credentials.

## Cloud upload

<Code code={`planview login --cloud-url ${appUrl.replace(/\/$/, '')}\nplanview upload --open ./report.html\nplanview upload --json ./report.html\nplanview logout`} lang="sh" />

Login opens browser sign-in and authorizes this computer for uploads. The saved
credential is upload-only. It cannot list, read, or delete cloud documents.
Logout revokes it on the server before removing the local credential; it needs
a connection. Browser sign-out and CLI logout are separate operations.

Use `--cloud-url` on `login`, or `PLANVIEW_CLOUD_URL`, to select another app origin.
Existing saved credentials remain tied to the origin used at login.
Cloud upload accepts standalone HTML up to 8 MiB. Cloud folder uploads are
[under review](../../reference/planned-features/).

## Automation

Errors go to stderr and failures return exit status 1. Successful commands write
their result to stdout. `--json` emits one JSON value for publication, cloud
upload, status, start, stop, restart, and clean. Avoid parsing human-readable
status messages.

```sh
planview help
planview help upload
planview skills install
```

The skill installer writes `planview` and `create-html` to `~/.agents/skills`.
It refuses existing directories unless `--force` is supplied.
