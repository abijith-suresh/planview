or save a document to your account and return to it later.

:::caution[Alpha storage is public]
The workspace checks account access, but UploadThing files have public direct
URLs during alpha. Use test content you are comfortable sharing.
:::

## Product name, repository name

The product is **plansplease**. The repository and command are still **planview**,
and the CLI package remains `@abijith-suresh/planview`. npm publication is currently
disabled; the CLI guide explains how to install a repository build.

These guides describe the implementation on `main` and identify where staging
has not deployed a change yet. [Features under review](./reference/planned-features/)
are separate from the current workflows.
